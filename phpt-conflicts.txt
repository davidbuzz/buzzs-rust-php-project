# Conflict keys php-src's tests lack (paths relative to modules/php-src).
#
# Some php-src tests share a file without declaring it (no --CONFLICTS-- section, no directory
# CONFLICTS file), so when they run at the same time one deletes or rewrites what the other is
# still using, and either can fail. C PHP's run-tests.php -j races them the same way. php-src is
# read-only here, so the keys are recorded in this file.
#
# phpt-runner reads this file by default and adds the keys to the tests' own conflict keys:
# tests that share a key never run at the same time. `--no-extra-conflicts` ignores it.
# One test per line: its path, then one or more keys, separated by white space; `#` starts a
# comment. Found with a scan for tests in one directory that delete the same literal file name
# (22 Nov 2026).
